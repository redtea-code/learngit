# Optimization Reading Group

将最优化教材内容整理成可讲、可核对、可编译的讨论班材料。优先复用用户已有的教材、TeX 模板和章节边界；不要把某一份讲稿中的偶然写法当成普遍定理。

## 工作入口

1. 先确认任务范围：教材、章节/小节、指定例子、需要的交付物（Beamer、PDF、证明 Markdown 或仅提纲）。
2. 检查当前目录中的源文件、模板和既有版本。若有“最优化”文件夹，优先阅读对应的 `.tex`、证明 `.md` 和根目录的 PPT 约定；不要只依据文件名推断已覆盖内容。
3. 把内容分为四类：定义与记号、推导、定理/证明、算法/例子。记录每个结论的假设、变量对象、步长条件和适用边界。
4. 对教材 PDF 做文字检索或摘录时，使用可用的 PyMuPDF（`fitz`）环境并保持 UTF-8；以教材原文核对公式编号、符号方向和定理条件。

## 统一教学主线

每一页或每一段只承担一个叙事任务，采用以下顺序组织：

`问题与动机 -> 定义/记号 -> 等价变换 -> 一次关键推导 -> 定理与条件 -> 小例子或算法 -> 结论含义与边界`。

主公式前用一句极短的陈述说明为什么需要它；公式后说明它带来的计算或理论意义。每个新符号首次出现时定义空间、维度和约束含义。连续推导使用对齐环境，逐次说明使用了可行性、共轭定义、Fenchel--Young、强凸性、半正定性或其他性质。

教材顺序优先，但只保留服务当前范围的前置知识。回顾通常不超过两页；不能用“教材指出”替代论证，也不能把后续章节的完整内容提前塞进当前报告。

## 章节路线

### 8.5 对偶算法

按此逻辑展开：复合目标的原始近似点梯度回顾；引入 `y=Ax` 和拉格朗日对偶；由强凸性证明共轭函数可微且梯度 Lipschitz；得到对偶近似点梯度；用 Moreau 分解转回原始--对偶更新；建立鞍点表示并介绍 PDHG、Chambolle--Pock；最后用 LASSO 展示共轭、邻近算子、软阈值和步长条件。

### 8.6 ADMM、DRS 与 LASSO

按此逻辑展开：两块线性等式约束模型；增广拉格朗日和缩放乘子；联合极小化的困难；ADMM 三步交替更新；KKT 条件；原始残差与对偶残差的推导；DRS 定义与不动点定理；DRS--ADMM 的逐步变量映射；LASSO 的一致性拆分、闭式更新与收敛边界。

### 8.7 随机优化

按此逻辑展开：有限和经验风险；全梯度；随机梯度/次梯度；动量、RMSProp、Adam 的共同骨架；一般凸收敛假设；先证明单步递推引理，再处理条件期望和噪声；望远镜求和；用 Jensen 不等式得到加权平均点的误差界；给出步长条件和典型的 `O(K^{-1/2})` 结论。明确结论针对平均点时，不得改写成最后一次迭代点收敛。

## 完整证明模式

证明 Markdown 比幻灯片更详细，固定包含：

1. 问题、记号、假设和目标结论。
2. 必需的预备结论：近端最优性条件、Fenchel--Young 或共轭次梯度互逆关系、次微分和规则及其正则性条件。
3. 按“由定义得到什么 -> 代入什么 -> 为什么可逆/可取等号”的顺序逐行推导。
4. 对双向结论分别证明正向和反向；明确每个包含关系、变量替换和唯一性来源。
5. 用一段逻辑链解释证明如何连接到算法，并单列适用条件、非唯一解和不等价边界。

针对范例中的结果保留以下细节：

- Moreau 分解先证明一般参数 `lambda>0`，最后再代入算法参数。
- DRS 不动点定理说明“不动点 <-> 最优解”的两个方向，并写出次微分和规则所需的正则性条件。
- DRS--ADMM 等价证明使用 `v^k` 等不冲突的记号；说明 `rho=t`、`tau=1`、`w^k` 的变量映射，以及子问题非唯一时必须选择相互对应的解。
- 随机次梯度收敛性先证明单步引理，再展开条件期望、望远镜求和和 Jensen；不要越过中间不等式直接声称收敛。

## Beamer 规范

- 默认沿用项目 `template.tex`：Madrid 主题、rose 配色、白底和蓝色标题栏，使用 `ctexcap`；可按需保留 `amsmath`、`amssymb`、`bm` 以及 `prox/argmin/argmax/R` 命令。
- 每页只有一个客观短标题，使用名词短语或结论性短语；可见文字全部为陈述句或名词短语，不用问号、宣传口号或“什么是/为什么/如何”式标题。
- 目录页兑现后续内容；页面之间写出文字转折。公式配短斜体动机句，长公式优先拆页，字号缩小只是次要手段。
- 定理和证明主链条尽量同页；不把整页做成嵌套色块，不添加花哨装饰。最后一页固定为“参考文献”，只列实际使用的教材、论文、数据集或可核验链接；正文不反复标注来源。
- 不设置独立“总结”页；最后一个实质内容页自然收束后进入参考文献。

## 例子与算法

例子按“原问题 -> 关键改写 -> 推导/计算 -> 结果含义”展开。优先选用教材已有的一维、低维或 LASSO 例子；每个例子必须服务于一个具体概念，例如乘子符号、对偶间隙、对偶范数、软阈值、残差或步长条件。算法页同时写清输入、更新顺序、输出对象、步长/正则参数和收敛所需假设。

## 交付前验证

对 TeX/PDF 交付执行双重 QA：

1. 使用 XeLaTeX 编译两次，使目录、导航和书签稳定；优先使用本机可用的 TeX Live `xelatex`，采用显式输出目录、`-jobname` 和正斜杠路径。
2. 在日志中筛查 `Fatal`、`Emergency`、`Undefined`、`Error`、`Overfull` 和严重 `Underfull`；字体替换警告单独判断。
3. 用绝对路径的 `pdftoppm` 或 `fitz` 将 PDF 渲染为 PNG，逐页至少检查标题、中文、公式、页脚、色块和边界；重点检查定理、长公式、表格和参考文献页。
4. 交付前核对 PDF 页数、指定章节是否完整、公式符号与教材是否一致、参考文献页是否存在，并确认注释掉的草稿没有被当成交付内容。
5. 保留既有源文件和历史版本；在同一主题修订时做可追踪修改，不覆盖无关材料。

## 质量边界

把“严格证明”“教学版主链条”“算法实现提示”分开标注。明确哪些是定理直接保证的，哪些依赖额外正则性或步长条件，哪些只是直觉或工程实现。遇到教材、旧讲稿和当前要求不一致时，以当前明确范围和可核验的公式为准，并记录调整理由。
